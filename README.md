# PropDevelopment — итоговый проект спринта 5

Репозиторий предназначен для выполнения заданий по архитектурному кейсу PropDevelopment. Результаты каждого задания будут храниться отдельно, чтобы их можно было проверять независимо.

## Ожидаемые артефакты

| Каталог | Ожидаемый результат |
| --- | --- |
| `Task1` | Скрипты и результаты анализа, предусмотренные заданием 1 |
| `Task2` | Обновлённые архитектурные схемы и пояснения к ним |
| `Task3` | Материалы по информационной безопасности |
| `Task4` | Модель ролей и прав доступа (RBAC) |
| `Task5` | Kubernetes-манифесты и сопутствующие конфигурации |
| `Task6` | Материалы демонстрационного расследования событий аудита |
| `Task7` | Итоговые архитектурные решения и рекомендации |

## Исходные материалы

При выполнении заданий используются предоставленные отдельно исходники:

- описание кейса PropDevelopment;
- `C4-diagram.png`;
- `PropDevelopment_С4_model.drawio.xml`;
- `IB.md`;
- шаблон RBAC.

Исходники в этот репозиторий не копируются.

Реальный файл `audit.log` не предоставлен. Поэтому в `Task6` будет использован явно маркированный synthetic/demo fixture. Он нужен только для демонстрации методики и не подтверждает, что фактический инцидент происходил.

## Будущие статические проверки

После появления соответствующих артефактов можно будет запускать, например:

```bash
bash -n Task1/*.sh
jq empty Task*/**/*.json
xmllint --noout Task*/**/*.xml
kubectl apply --dry-run=client -f Task5/
```

Конкретные команды потребуется уточнить по фактической структуре и форматам созданных файлов.
