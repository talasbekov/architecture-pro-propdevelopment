# PropDevelopment — итоговый проект спринта 5

Репозиторий предназначен для выполнения заданий по архитектурному кейсу PropDevelopment. Результаты каждого задания будут храниться отдельно, чтобы их можно было проверять независимо.

## Ожидаемые артефакты

| Каталог | Ожидаемый результат |
| --- | --- |
| `Task1` | Mind map в формате draw.io с классификацией данных и рисками |
| `Task2` | Security checklist в формате Markdown |
| `Task3` | Контекстная и контейнерная C4-диаграммы в формате draw.io, а также требования к интеграциям |
| `Task4` | Описание ролей в `roles.md` и три скрипта для работы с RBAC |
| `Task5` | Kubernetes NetworkPolicy в формате YAML |
| `Task6` | `analysis.md`, `audit-extract.json` и скрипт фильтрации событий аудита |
| `Task7` | Полный набор материалов по PSA и Gatekeeper: insecure- и secure-манифесты, команды или скрипты проверки, audit policy и README для ревьюера |

## Исходные материалы

При выполнении заданий используются предоставленные отдельно исходники:

- описание кейса PropDevelopment;
- `C4-diagram.png`;
- `PropDevelopment_С4_model.drawio.xml`;
- `IB.md`;
- шаблон RBAC.

Исходники в этот репозиторий не копируются.

Реальный файл `audit.log` не предоставлен. Будущий `Task6/audit-extract.json` — синтетический демонстрационный пример с явной меткой `synthetic/demo`: он не извлечён из настоящего `audit.log`, используется только для демонстрации методики и не подтверждает реальный инцидент.
